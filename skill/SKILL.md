# SolidWorks: моделирование скриптами

Набор — git-репозиторий, общий для нескольких машин. Корень находится так:
переменная `SWKIT_HOME`, иначе `~/.claude/skills/solidworks` — junction,
ведущий в `<корень>/skill`.

## ОБЯЗАТЕЛЬНО: синхронизация репозитория

Набор правится с разных машин. Работа со старой копией приводит к
конфликтам и к потере уже найденного знания, поэтому:

**В начале работы — подтянуть изменения.** Первым действием, до построения
и до чтения базы:

```bash
cd "$SWKIT_HOME" && git pull --rebase
```

Если `git pull` сообщил о конфликте — разобрать его сразу, не начиная
моделирование: база знаний важнее текущей задачи.

**После каждого изменения набора — отправить.** Не в конце сессии, а сразу
после того, как правка сделана и проверена:

```bash
cd "$SWKIT_HOME" && git add -A && git commit -m "кратко что и почему" && git push
```

Отправлять нужно после: новой записи в `knowledge/`, правки `swkit/`,
изменения `SKILL.md`, обновления `CHANGELOG.md`. Одна правка — один коммит
с внятным сообщением: через месяц по нему придётся понимать, что менялось.

Если `git push` отклонён (кто-то успел раньше) — `git pull --rebase`, затем
`git push` снова.

**`gh auth login` из этой оболочки запускать НЕЛЬЗЯ** — команда интерактивная,
ждёт нажатия Enter и зависает навсегда без единой строки вывода. Проверять
только так:

```bash
gh auth status        # отвечает мгновенно
```

Не авторизован — остановиться и попросить человека выполнить вход в своём
терминале. Подробности и остальное про репозиторий —
`knowledge/40_СРЕДА/40-02`.

Модели, экспорт и снимки в репозиторий не попадают: они в `.gitignore`.
Репозиторий — это инструмент, а не архив проектов.

## Первое действие

```python
import os
import sys
sys.path.insert(0, os.environ["SWKIT_HOME"])
import swkit as sw

sw.utf8_console()          # иначе print с кириллицей упадёт
app = sw.app()             # подключение к ЗАПУЩЕННОМУ SolidWorks
```

Готовый резолвер пути, работающий и без `SWKIT_HOME`, — в
`templates/new_project/build.py`, функция `kit_root()`. Копируйте его в
скрипты проектов, а не зашивайте путь: набор на разных машинах лежит
по-разному.

SolidWorks должен быть запущен вручную до начала работы.

## Минимальный рабочий цикл

```python
doc = sw.new_part(app)

with sw.Sketch(doc, sw.TOP) as sk:        # 0 Спереди, 1 Сверху, 2 Справа
    sk.rect(0, 0, 2000, 1000)             # ВСЕГДА миллиметры
sw.extrude(doc, sk.feature, 200)

with sw.Sketch(doc, sw.TOP) as sk2:
    sk2.rect(500, 300, 900, 700)
sw.cut(doc, sk2.feature, end=sw.THROUGH_ALL)

sw.check_part(doc, "Плита",
              expect_volume_mm3=2000*1000*200 - 400*400*200,
              expect_box_mm=[2000, 200, 1000])
sw.save_as(doc, r"C:\проект\Плита.SLDPRT")
sw.shot(doc, r"C:\проект\вид.png", view="iso")
sw.close(app, doc)
```

## Шесть правил, нарушение которых стоит часа

1. **Миллиметры и градусы** на входе `swkit`. API работает в метрах и
   радианах, перевод — внутри библиотеки. При прямом вызове API переводите сами.
2. **Плоскости — по индексу, не по имени.** `sw.TOP`, а не `"Сверху"`:
   имена зависят от языка интерфейса.
3. **Направление выреза обратное вытяжке.** У `sw.cut` умолчание
   `reverse=True`, у `sw.extrude` — `False`. Это не опечатка.
4. **Проверять результат числом И глазами.** Деталь, которая открылась, —
   ещё не правильная деталь.
5. **Сборку сохранить ДО вставки компонентов** и открыть детали через
   `sw.preload` — иначе `AddComponent5` вернёт None.
6. **Никогда не выдавать непроверенное за проверенное** — ни в коде, ни в
   отчёте, ни в базе знаний.

## Состав библиотеки

## Обновление набора по ходу работы

Набор рассчитан на правку во время проектирования, а не отдельным заходом.

* Нашли поведение API, расходящееся с ожиданием, и разобрались — **сразу**
  запись в `knowledge/30_ГРАБЛИ` по шаблону из `00_ПРАВИЛА.md`, строка в
  `INDEX.md`, строка в `CHANGELOG.md`.
* Написали функцию, полезную не только этому проекту — перенести в `swkit`.
* **После любой из этих правок — коммит и `git push`** (см. раздел о
  синхронизации выше). Знание, оставшееся на одной машине, для остальных
  не существует.

Файлы обычные, правятся через Write/Edit, перезапуск Claude Code **не нужен**:
изменения действуют со следующего чтения. Именно поэтому набор сделан
скиллом, а не MCP-сервером.
