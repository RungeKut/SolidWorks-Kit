# Мелкие грабли, каждая из которых стоила времени

Здесь собрано то, что не заслуживает отдельного файла, но обязательно
выстрелит. Порядок — по цене ошибки.

---

## 1. Модальное окно вешает скрипт навсегда

**Цена: часы.** Аддины (в первую очередь SOLIDWORKS CAM) при перестроении
показывают предупреждения. Модальное окно останавливает COM-вызов, и скрипт
висит бесконечно. Снаружи это неотличимо от тяжёлой геометрии: процесс жив,
процессор занят, прогресса нет.

Решение — фоновый сторож, закрывающий такие окна по заголовку:

```python
app = sw.app()          # сторож поднимается автоматически
app = sw.app(watch_dialogs=False)   # если мешает
```

Реализация: `swkit/dialogs.py`. Список заголовков — в `dialogs.NUISANCE`;
встретив новое мешающее окно, дополните список и допишите строку сюда.

---

## 2. NewDocument возвращает None при успешном создании

**Цена: десятки минут.** Документ создаётся, на экране появляется, а вызов
возвращает `None`.

```python
doc = sw.NewDocument(tpl, 0, 0, 0)
if doc is None:
    doc = sw.ActiveDoc          # обязательный запасной путь
```

`swkit.new_part()` и `swkit.new_assembly()` это делают. Проверено
20.09.2026: на этой установке `NewDocument` возвращал `None`, а
`sw.ActiveDoc` — корректный документ сборки (`GetType` = 2).

То же относится к `OpenDoc6`: может открыть документ и вернуть `None`.

## 3. Шаблон по умолчанию бывает не задан

`GetUserPreferenceStringValue(8)` возвращает пустую строку на свежей
установке, и `NewDocument("")` молча даёт `None`.

`swkit.find_template()` спрашивает настройку, а при пустом ответе ищет на
диске по маскам `C:\ProgramData\SolidWorks\**\*.prtdot` и
`C:\Program Files\SOLIDWORKS*\**\*.prtdot`. Предпочитает ГОСТ-шаблон,
MBD-шаблоны ставит последними — они настроены под мелкие детали.

На этой машине: `C:\ProgramData\SolidWorks\SOLIDWORKS 2025\templates\gost-part.prtdot`.

## 4. Плоскости нельзя искать по имени

Имена базовых плоскостей зависят от языка интерфейса: «Спереди» / «Front» /
«Vorne». Скрипт с `SelectByID2("Спереди", "PLANE", ...)` ломается на
англоязычной установке.

Правильно — обходить дерево и брать по порядку:

```python
planes = sw.base_planes(doc)     # [Спереди, Сверху, Справа]
sw.select_plane(doc, sw.TOP)     # по индексу
```

Порядок в дереве постоянен: 0 — Спереди, 1 — Сверху, 2 — Справа. Проверено
на русской установке 2025 SP04.

Важно: первый элемент дерева — **не плоскость**, а папка `Favorites`
(тип `FavoriteFolder`). Фильтровать по `GetTypeName2() == "RefPlane"`
обязательно.

## 5. Файлы ~$Имя.SLDPRT — не документы

Служебные файлы блокировки. При пакетной обработке по маске `*.SLDPRT` они
попадают в список, и попытка открыть даёт невнятную ошибку в середине
прогона.

```python
files = [f for f in files if not os.path.basename(f).startswith("~$")]
```

`swkit.export.is_real_document()` и `swkit.export.batch()` это делают.

---

## 6. print() с кириллицей падает

Консоль Windows по умолчанию в кодировке 866, Python пишет UTF-8:
`UnicodeEncodeError` в середине построения, после которого непонятно,
сохранилась модель или нет.

Первой строкой каждого скрипта:

```python
import swkit as sw
sw.utf8_console()
```

## 7. Единицы API — метры и радианы

Цилиндр диаметром 40 мм — это радиус `0.02`. Ошибка в 1000 раз не всегда
заметна: модель строится, просто она микроскопическая или гигантская, а
габарит «формально правильный» в своих единицах.

Вся библиотека `swkit` принимает **миллиметры и градусы** и переводит внутри.
При прямых вызовах API переводите сами: `swkit.units.m(200)`.

---

## 8. Заблокированный сеанс RDP ломает графику

Под заблокированным сеансом у SolidWorks нет рабочего стола: снимки экрана и
операции с видами отваливаются, хотя геометрия считается. Не запускать
построение с видами под заблокированным RDP.

---

## 9. Открытый документ держит файл

Документ, оставшийся открытым после предыдущего прогона, мешает перезаписи.
Перед пересборкой:

```python
sw.close_all(app)
```

---

## 10. Флаг --real у MCP-сервера

Если используется MCP-сервер `solidworks`: без ключа `--real` он стартует в
**mock-режиме** и отвечает «готово» на все команды, ничего не делая
(`mock_mode = not args.real`). Получается правдоподобная имитация работы.
