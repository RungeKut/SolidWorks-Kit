# Вырез режет в сторону, обратную вытяжке

## Что происходит

Плита построена так: эскиз на плоскости «Сверху», вытяжка на 200 мм
(`reverse=False`) — материал уходит ВВЕРХ от плоскости.

Теперь нужен сквозной проём. Эскиз — на той же плоскости «Сверху».
Логично ожидать, что `reverse=False` прорежет тот же материал. Не прорежет:

```
FeatureCut4 вернул None
```

## Почему

У `FeatureExtrusion3` и `FeatureCut4` третий аргумент (`dir`) отсчитывается
от плоскости эскиза в противоположных смыслах. У выреза `reverse=False`
направляет рез в ту сторону, где материала нет; резать нечего, и SolidWorks
возвращает `None` — без исключения и без внятного сообщения.

При глухом вырезе со смещением эффект тот же по сути: `reverse=False` снимает
слой НИЖЕ отметки вместо материала над ней.

## Как правильно

```python
import swkit as sw

doc = sw.new_part(app)
with sw.Sketch(doc, sw.TOP) as sk:
    sk.rect(0, 0, 2000, 1000)
sw.extrude(doc, sk.feature, 200)            # вверх, reverse=False

with sw.Sketch(doc, sw.TOP) as sk2:
    sk2.rect(500, 300, 900, 700)
sw.cut(doc, sk2.feature, end=sw.THROUGH_ALL)  # reverse=True ПО УМОЛЧАНИЮ
```

В `swkit.cut()` значение по умолчанию — `reverse=True`, в отличие от
`swkit.extrude()`, где `reverse=False`. Разные умолчания у двух похожих
функций сделаны сознательно: они соответствуют тому, что нужно на практике.

Кроме того, `swkit.cut()` по умолчанию делает **автоподбор направления**:
если первая попытка вернула `None`, вызов повторяется с обратным знаком.
Отключается через `auto_direction=False`. С `verbose=True` печатается,
какое направление сработало.

## Как неправильно

```python
sw.cut(doc, sk2.feature, end=sw.THROUGH_ALL, reverse=False)   # вернёт None
```

И отдельно — **не** использовать `THROUGH_ALL_BOTH` (код 8) как «надёжный
вариант на всякий случай»: на проверке он не сработал (см. ниже). Для реза
в обе стороны есть `both_directions=True`, который передаёт условие
окончания в оба направления сразу.

## Чем подтверждено

Плита 2000×1000×200, проём 400×400, ожидаемый снимаемый объём 32 000 000 мм³:

```
THROUGH_ALL, reverse=False       НЕТ  FeatureCut4 вернул None
THROUGH_ALL, reverse=True        OK   снято 32 000 000 мм3
THROUGH_ALL_BOTH (код 8)         НЕТ  FeatureCut4 вернул None
both_directions=True             OK   снято 32 000 000 мм3
BLIND 200, reverse=True          OK   снято 32 000 000 мм3
```

Автоподбор проверен отдельно: вызов с заведомо неверным `reverse=False`
повторился и дал ровно 32 000 000 мм³. Важное следствие — **эскиз после
неудачной попытки выреза остаётся пригодным** — пересоздавать его
«на всякий случай» не нужно.

## То же самое со смещением начала

Правило распространяется и на `start_offset`. Ниши колёс в кузове Cybertruck
вырезаются от плоскости «Справа» со смещением 700 мм наружу; вытяжка зеркал
с тем же смещением идёт наружу при `reverse=False`, а **вырез при том же
`reverse=False` уходит внутрь**. Пара, дающая два симметричных кармана:

```python
sw.cut(doc, sk, 400, end=sw.BLIND, reverse=True,  start_offset=700)   # правый
sw.cut(doc, sk, 400, end=sw.BLIND, reverse=False, start_offset=700,
       flip_start=True)                                               # левый
```

Проверять надо не тем, что вызов прошёл — при неверном знаке он проходит тоже,
просто вырезает не там. Смотреть на объём или на площадь появившихся граней:
карман 700..1000 снимает 300 мм глубины, а ушедший внутрь 300..700 — 400 мм.
