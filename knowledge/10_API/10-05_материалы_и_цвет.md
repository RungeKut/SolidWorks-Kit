# Материалы и цвет

## Назначение материала

```python
sw.set_material(doc, sw.materials.DEFAULT_DB,
                "Железобетон монолитный B25",
                expect_density=2500)
```

Три условия, все нарушаются легко:

1. **Материал назначается по ГОТОВОМУ ТЕЛУ.** До первой вытяжки вызов молча
   не действует.
2. **Ошибка не возвращается.** `SetMaterialPropertyName2` с несуществующим
   именем материала не падает — материал просто не назначается, и масса
   модели считается по плотности шаблона.
3. **Обратное чтение имени не работает.** См. ниже.

## Проверять надо ПЛОТНОСТЬЮ, а не именем

Напрашивающаяся проверка — перечитать назначенное имя:

```python
got = doc.GetMaterialPropertyName2(config, "")     # НЕ РАБОТАЕТ
```

При позднем связывании это даёт `Несовпадение типов` на аргументе 2: второй
аргумент — **выходной**, туда возвращается путь к базе. С правильным
`VARIANT(VT_BYREF | VT_BSTR, "")` вызов проходит, но **возвращает пустую
строку**, хотя материал назначен.

Проверено 20.09.2026: после назначения «Простая углеродистая сталь»
обратное чтение имени дало `''`, а плотность — `7800.0`. То есть материал
применён, просто прочитать его имя этим путём нельзя.

Поэтому проверка идёт по плотности — она и по существу лучше: подтверждает
физическое свойство, которое влияет на массу, а не совпадение строки.

```python
mp = sw.mass_properties(doc)
assert abs(mp["density"] - 2500) < 1     # железобетон B25
```

`swkit.set_material` делает это сам: берёт ожидаемую плотность из аргумента
`expect_density`, а если он не задан — из `sw.materials.DENSITY` по имени
материала. Если плотность неизвестна ни оттуда, ни оттуда, печатается
предупреждение «назначен, но НЕ ПРОВЕРЕН» — молча считать материал
назначенным нельзя.

Словарь `sw.materials.DENSITY`: имя материала -> кг/м³.

## Своя база материалов

Штатная база не содержит ни железобетона B25, ни каменной ваты, ни ЛДСП.
Без них масса модели не имеет смысла.

Файл `.sldmat` — это **XML в кодировке UTF-16**. Он должен быть
зарегистрирован: Настройки -> Расположение файлов -> Базы данных материалов.

```python
from swkit import materials

materials.write({
    "Строительные материалы": materials.STROITELNYE,
    "Мебель и оборудование": materials.MEBEL,
})
```

Функция перезаписывает **только перечисленные классификации**, не трогая
остальные материалы файла. Перед первой записью создаётся `.bak`, и все
последующие записи идут от него — поэтому повторный запуск идемпотентен и
не накапливает мусор.

Свой материал:

```python
m = materials.Material(
    name="Фанера берёзовая ФСФ 3 мм",
    density=700, E=9.0e9, nu=0.07, strength=3.0e7,
    k=0.15, c=1700, rgb="d9b98a", hatch="дерево")
materials.write({"Дерево и фанера": [m]})
```

Модуль сдвига G считается из E и nu автоматически.

## Цвет

Цвет — косметика и **никогда не должен ронять построение**:

```python
sw.set_color(doc, (0.61, 0.61, 0.62))                    # деталь
sw.set_color(doc, (0.9, 0.9, 0.9), component=comp)       # компонент сборки
sw.set_color(doc, (0.5, 0.7, 1.0), transparency=0.7)     # остекление
```

`MaterialPropertyValues` принимает массив из 9 чисел:
R, G, B, ambient, diffuse, specular, shininess, transparency, emission.
Цвета — доли от 0 до 1, не 0–255.

Цвет компонента в сборке перекрывает цвет детали. Это удобно, чтобы
раскрасить компоненты по материалу согласно легенде, не меняя сами детали.
