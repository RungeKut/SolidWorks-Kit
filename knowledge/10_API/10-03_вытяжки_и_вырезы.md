# Вытяжки и вырезы

Самое неудобное место API: два метода с двумя десятками позиционных
аргументов, где перепутанная позиция даёт не ошибку, а неверную геометрию.

## Эскиз

```python
import swkit as sw

with sw.Sketch(doc, sw.TOP) as sk:       # 0 Спереди, 1 Сверху, 2 Справа
    sk.rect(0, 0, 2000, 1000)            # мм
    sk.circle(500, 500, 120)             # по ДИАМЕТРУ
    sk.poly([(0, 0), (100, 0), (50, 80)])
feat = sk.feature                        # объект эскиза для вытяжки
```

Контур **обязан быть замкнут**. Незамкнутый даёт `None` от вытяжки без
объяснения — это причина номер один.

Несколько контуров в одном эскизе: внешний плюс внутренние дают вытяжку с
отверстиями за один вызов. Приём хорошо работает на крупных деталях
сложного силуэта: весь профиль с внутренними проёмами и вырезами по контуру
строится одной вытяжкой, а не серией операций.

Оговорка: **похожие** контуры в одном эскизе стягиваются друг к другу
автопривязками, и геометрия выходит неверной молча — см.
[30-09](../30_ГРАБЛИ/30-09_контуры_в_одном_эскизе_слипаются.md).

## Вытяжка

```python
sw.extrude(doc, sk.feature, depth=200)                      # глухая, вверх
sw.extrude(doc, sk.feature, 200, reverse=True)              # вниз
sw.extrude(doc, sk.feature, 800, start_offset=200)          # с отметки 200 мм
sw.extrude(doc, sk.feature, 1000, both=True)                # симметрично
sw.extrude(doc, sk.feature, 200, merge=False)               # отдельным телом
```

### Разбор позиций FeatureExtrusion3

| № | Имя | Значение в swkit |
|---|---|---|
| 1 | `sd` | True — одно направление |
| 2 | `flip` | False — сторона материала |
| 3 | `dir` | `reverse` — обратное направление |
| 4 | `t1` | условие окончания, направление 1 |
| 5 | `t2` | условие окончания, направление 2 |
| 6 | `d1` | глубина 1, **метры** |
| 7 | `d2` | глубина 2, метры |
| 8–9 | `dchk1/2` | уклон включён |
| 10–11 | `ddir1/2` | уклон наружу |
| 12–13 | `dang1/2` | углы уклона, **радианы** |
| 14–15 | `offsetReverse1/2` | |
| 16–17 | `translateSurface1/2` | |
| 18 | `merge` | объединить с телом |
| 19 | `useFeatScope` | True |
| 20 | `useAutoSelect` | True |
| 21 | `t0` | начальное условие (0 или 3) |
| 22 | `startOffset` | смещение начала, метры |
| 23 | `flipStartOffset` | |

### Условия окончания (swEndConditions_e)

| Код | Имя | Проверено |
|---|---|---|
| 0 | `BLIND` — на расстояние | да |
| 1 | `THROUGH_ALL` — насквозь | да |
| 2 | `UPTO_NEXT` | нет |
| 4 | `UPTO_SURFACE` | нет |
| 6 | `MIDPLANE` — от средней поверхности | нет |
| 8 | `THROUGH_ALL_BOTH` | **не сработал на вырезе** |

### Начальное условие (swStartConditions_e)

`0` — от плоскости эскиза, `3` — смещение от плоскости эскиза
(`START_OFFSET`). При `start_offset != 0` третий аргумент обязан быть `3`,
иначе смещение игнорируется молча.

### Про MIDPLANE

`MIDPLANE` (код 6) в `swkit` доступен, но **надёжнее `both=True`** — две
глухие стороны по половине глубины: условие `MIDPLANE` при позднем
связывании отрабатывает не всегда. Отдельно `MIDPLANE` на текущей
установке не перепроверялся.

## Вырез

```python
sw.cut(doc, sk.feature, end=sw.THROUGH_ALL)               # reverse=True по умолчанию
sw.cut(doc, sk.feature, depth=100, end=sw.BLIND)
sw.cut(doc, sk.feature, end=sw.THROUGH_ALL, both_directions=True)
sw.cut(doc, sk.feature, depth=200, start_offset=900)      # проём окна
```

**Направление у выреза обратное вытяжке** — отдельная запись
[30-02](../30_ГРАБЛИ/30-02_направление_выреза.md). По умолчанию
`reverse=True` и включён автоподбор.

`FeatureCut4` в 2025 принимает **27 аргументов**; сигнатура из старой
документации на 26 не проходит. Позиции 1–17 совпадают с вытяжкой, дальше:

| № | Имя |
|---|---|
| 18 | `normalCut` |
| 19 | `useFeatScope` |
| 20 | `useAutoSelect` |
| 21 | `assemblyFeatureScope` |
| 22 | `autoSelectComponents` |
| 23 | `propagateFeatureToParts` |
| 24 | `t0` — начальное условие |
| 25 | `startOffset` |
| 26 | `flipStartOffset` |
| 27 | `optimizeGeometry` |

## Почему вызов вернул None

По частоте:

1. контур эскиза не замкнут;
2. эскиз самопересекается;
3. у выреза — неверное направление (см. 30-02);
4. вырез не пересекает тело;
5. глубина 0;
6. выбран не эскиз, а другой объект дерева;
7. вырез удалил бы тело целиком.

Исключение при этом **не бросается** — возвращается `None`. Поэтому
`swkit.extrude` и `swkit.cut` проверяют результат и бросают `RuntimeError`
с перечнем причин: тихий `None` порождает ошибку далеко от места её
возникновения.

## Вращение

```python
sw.revolve(doc, sk.feature, axis=None, angle=360)
```

Ось должна быть выбрана вместе с эскизом. Проверено мало — при затруднениях
смотрите `FeatureRevolve2` в официальной документации.
