# Виды, снимки и экспорт

## Стандартные виды

```python
sw.shot(doc, r"...\вид_iso.png", view="iso")
sw.shot_set(doc, OUT, "деталь", views=("iso", "front", "right", "top"))
```

Коды `swStandardViews_e`: 1 спереди, 2 сзади, 3 слева, 4 справа, 5 сверху,
6 снизу, 7 изометрия, 8 триметрия, 9 диметрия.

Вызывать `ShowNamedView2("", код)` — **числом, а не русским именем**:
имена зависят от языка интерфейса.

## Когда вертикаль не Y

Стандартная изометрия SolidWorks предполагает «вверх = Y». Если в модели
вверх — это Z (автомобильная система координат, строительная модель),
штатная изометрия покажет объект **лежащим на боку**.

Тогда ориентация задаётся явно вектором «вверх» и вектором на зрителя:

```python
sw.shot(doc, path, sw=app, up=(0, 0, 1), normal=(-0.55, -0.70, 0.45))
sw.shot_set_z_up(app, doc, OUT, "машина")   # готовый набор из шести видов
```

`IModelView::Orientation3` хранит матрицу **по столбцам**; её строки — оси
вида (вправо, вверх, на зрителя) в системе модели. Пересчёт делает
`swkit.views.set_view`.

## Снимок — это захват графической области

`SaveAs` с расширением `.png` сохраняет то, что на экране. Отсюда следствия:

* SolidWorks обязан быть видимым, не под заблокированным сеансом RDP;
* размер снимка определяется размером окна — разверните окно, если нужна
  детализация;
* флаг сохранения — **копия** (2), иначе модель переименуется в `вид.png`
  (см. [30-03](../30_ГРАБЛИ/30-03_SaveAs_флаг_копии.md)).

Для скрытия деталей перед съёмкой разреза:

```python
sw.show(asm, "02_Плита_перекрытия-1", visible=False)
sw.shaded(doc)
```

## Зачем вообще снимать виды

Числовая проверка габаритов **не отвечает на вопрос «похоже ли это на то,
что задумано»**. Модель кузова автомобиля может пройти все числовые
проверки, будучи сплошным клиновидным бруском: габарит совпадёт с
прототипом точно, а узнаваемости не будет никакой.

Правило: после каждого этапа построения снимать виды и **смотреть на них**.
Подробнее — [20-02](../20_ПРИЁМЫ/20-02_проверка_модели.md).

## Экспорт

```python
sw.set_step_format(app, ap=214)                  # AP214 с цветами
sw.export(doc, r"...\Деталь.STEP")
sw.export_batch(app, [PARTS_DIR, ASM_DIR], OUT_DIR, fmt="STEP")
```

Формат определяется расширением: `.step/.stp`, `.iges/.igs`, `.stl`, `.pdf`,
`.dwg`, `.dxf`, `.x_t`, `.png`.

Пакетный экспорт отсеивает файлы `~$Имя.SLDPRT` — это служебные метки
блокировки, а не документы.

Настройка формата STEP: `SetUserPreferenceIntegerValue(213, 214)`.
