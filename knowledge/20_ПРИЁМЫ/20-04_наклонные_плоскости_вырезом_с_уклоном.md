# Наклонная плоскость вырезом с уклоном

## Задача

Нужно срезать тело плоскостью, наклонённой сразу в двух направлениях
относительно базовых: например, скос боковой стенки, нижняя кромка которого
равномерно поднимается вдоль детали, а сама грань при этом ещё и завалена
внутрь.

Очевидные пути — справочная плоскость по трём точкам или вырез-по-сечениям —
оба громоздкие: справочную плоскость через COM надо строить по точкам 3D-эскиза,
лофт требует двух эскизов на двух плоскостях.

## Приём

**Вырез с уклоном заметает плоскость, наклонную к плоскости эскиза.**
Плоский участок контура при вытягивании с уклоном порождает плоскую грань:
на расстоянии `d` от эскиза ребро смещено перпендикулярно самому себе на
`d * tan(δ)`.

Значит, для плоскости, наклонённой на `lean` мм поперёк на каждый мм вдоль
направления вытягивания:

```python
def draft(lean, slope):
    """Угол уклона, дающий наклон `lean` мм на мм глубины,
    для линии, идущей в эскизе с наклоном `slope`."""
    return math.degrees(math.atan(lean / math.hypot(1.0, slope)))
```

`slope` — наклон самой линии в эскизе; делитель нужен потому, что уклон
смещает ребро **перпендикулярно ребру**, а не вдоль оси эскиза.

В эскизе рисуется **след искомой плоскости на уровне плоскости эскиза**, а
удаляемая область — всё по одну сторону от этого следа, с запасом далеко за
габарит. Уклон «наружу» растит область по ходу вытягивания, «внутрь» — сужает.

```python
# ниже кромки стенка вертикальная (X = ±1000),
# выше грань завалена внутрь на 0.35 мм на мм высоты
X0    = HALF + LEAN * EDGE_V0        # след на уровне плоскости эскиза
SLOPE = LEAN * EDGE_K                # кромка поднимается вдоль детали
wedge = [(X0 + SLOPE*u0, u0), (X0 + SLOPE*u1, u1),
         (FAR, u1), (FAR, u0)]        # FAR — далеко за габаритом

sw.cut(doc, sk, 2600, end=sw.BLIND, reverse=True,
       draft_deg=draft(LEAN, SLOPE), draft_outward=True)
```

## Что выбрать базовой плоскостью

Ту, при которой угол уклона умеренный. Одна и та же плоскость режется от
любой из трёх базовых, но требуемый угол разный, а большие уклоны SolidWorks
считает неохотно:

| База | Вытягивание | Угол в разобранном примере |
|---|---|---|
| «Сверху» | вверх | **19.3°** — взят |
| «Спереди» | вдоль детали | 1.0° — тоже годится, но след считать труднее |
| «Справа» | поперёк | 72° — практически нерабочий |

Правило: чем ближе направление вытягивания к направлению, вдоль которого
плоскость меняется быстрее, тем меньше угол.

## Проверка

Числом, а не глазом: у готового тела найти плоские грани и сравнить их
нормали и смещения с расчётными.

```python
surf = sw.v(face.GetSurface)
if sw.v(surf.IsPlane):
    p = sw.v(surf.PlaneParams)        # nx, ny, nz, px, py, pz
    n, pt = p[:3], p[3:]
    offset = sum(a*c for a, c in zip(pt, n))     # метры
```

На проверочной детали обе наклонные грани сошлись с расчётом:
`|cos| = 1.000000`, смещение совпало до пятого знака, и на сторону получилась
**одна** плоская грань, а не набор осколков. Если граней оказалось несколько
или нормаль не сошлась — уклон ушёл не в ту сторону, меняйте `draft_outward`.

## Грабли

* `draft_outward` не угадывается из общих соображений: при неверном значении
  плоскость уходит от тела и вырез не режет ничего (объём не меняется) либо
  срезает лишнее. Сравнивайте объём до и после.
* Два зеркальных клина в одном эскизе не должны пересекаться **на уровне
  эскиза**; на глубине они разойдутся или сойдутся — это уже не мешает,
  но самопересечение контура в эскизе даёт `None` без объяснений.
* Дальние рёбра контура тоже смещаются уклоном. Уводите их за габарит с
  запасом не меньше `глубина * tan(δ)`.
